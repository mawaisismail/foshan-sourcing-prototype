# Foshan Direct: sourcing prototype

Clickable prototype for a factory-direct furniture sourcing site (Foshan to India):

- **Catalog**: 80 sample products, category/price filters, search, sort, material and size variants, MOQ and lead time
- **Quote basket** instead of checkout: INR pricing, indicative GST at 18%, WhatsApp-first quote request
- **Manager admin**: 8-stage order pipeline (enquiry, quote, contract, factory deposit, production, QC, shipping and customs, delivery), quote list with manager assignment, CSV bulk import and export

Static HTML/JS prototype (data in localStorage). The production build would be Next.js + headless CMS/Postgres with manager auth, staging deploys and WhatsApp notifications.
